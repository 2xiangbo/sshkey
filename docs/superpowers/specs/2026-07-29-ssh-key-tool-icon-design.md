# SSH 密钥工具图标设计

## 目标

为 SSH 密钥生成工具制作一枚与 XXcodex 启动器同系列、但功能含义清晰可区分的 Windows 应用图标。

## 视觉方案

采用已确认的 A 方案“密钥核心”：

- 深色圆角方形背景，延续启动器图标的深蓝黑基调。
- 保留青色与蓝色交织的双 X 主体及轻微发光效果。
- 中央使用荧光绿色钥匙符号，直接表达 SSH 密钥生成。
- 图形保持粗线条和高对比度，确保在 Windows 16px 小图标中仍可辨认。
- 不增加文字、阴影装饰或复杂网络节点。

## 输出资产

在项目内保存以下源资产：

- 可维护的 SVG 矢量源文件。
- 1024 x 1024 PNG 预览与高分辨率位图。
- 包含 16、24、32、48、64、128、256 像素图层的 Windows ICO。

## 应用集成

- 在项目文件中设置 `ApplicationIcon`，使发布后的 EXE 使用新图标。
- 窗口运行时加载同一个 ICO，确保窗口标题、任务栏和 Alt+Tab 图标一致。
- 不修改现有界面布局、SSH 流程或用户数据。

## 验证

- 检查 SVG、PNG 和 ICO 均可正常读取。
- 检查 ICO 包含全部目标尺寸。
- 运行完整自动化测试。
- 发布单文件、自包含的 win-x64 EXE。
- 启动发布文件并确认进程正常响应。
- 最终文件名为 `SshKeySetupTool-v10.exe`。
